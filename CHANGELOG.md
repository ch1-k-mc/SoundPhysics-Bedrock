# Changelog

## 0.1.0

First release, for Minecraft: Bedrock Edition 1.26.60 / LeviLamina 26.60.x.

- Occlusion, reverb, shared airspace, sound direction and underwater filtering, ported from Sound Physics Remastered 1.5.4
- Four reverb buses with the original's parameters
- All settings of the original, with the same keys and default values, in `mods/SoundPhysics/config/`
